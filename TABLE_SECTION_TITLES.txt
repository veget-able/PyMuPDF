중앙 섹션 제목 및 반복헤더 표 분리 / 2026-11-14

반영 기능
- 반복 헤더의 열 이름을 정규화한 뒤 서로 다른 비어 있지 않은 라벨 2종 이상 요구. 동일한 생략 표식의 반복으로 비교표를 분리하는 경로 방지.
- 각 반복 블록 앞에 실제 단독 bold 섹션 제목이 있고 본문이 이어지면, 실제 단어 bbox의 중앙 정렬과 원문 소속을 확인해 제목 행에서 표 분리.
- 중앙 기준은 전체 행 폭의 5%이며 기존 구간 중앙 판정에서 재사용. 파일명·GT·학습 사례 문자열을 판정에 사용하지 않음.
- 내부 native 세로 구획·다른 실제 단어·rowspan 교차·불완전 열·불명확 자료는 제목 범위 확장 거부.
- 최종 strict placement가 동일한 제목·행 영역·실제 단어 집합을 유지하면 제목 bbox를 전폭으로 확장하고 논리 열 수와 같은 colspan 생성. 제목 원문 속성 및 본문 셀 유지.
- _table_sections.py는 입력 자료를 전달받는 내부 helper이며 모델·PDF 추출 실행 없음. 기존 문자·단어·도형 캐시 및 _WordCenterIndex 재사용.
- table.py의 refine 경로에 직접 배선, HTML 문자열 후편집 없음. setup.py wheel 파일 목록에 신규 모듈 포함. 기본 refine=False 경로 유지.
